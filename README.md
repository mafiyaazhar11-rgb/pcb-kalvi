# PCB Kalvi · பிசிபி கல்வி

Interactive PCB learning app. Every board is drawn as a digital diagram you can rotate, tilt and flip, and every numbered part is explained in English and Tamil.

## What's inside
- 27 boards: Arduino Uno, Nano, Mega, Pro Mini, NodeMCU ESP8266, ESP‑01, Wemos D1 Mini, ESP32 DevKit, ESP32‑CAM, Raspberry Pi Pico, Raspberry Pi 4, STM32 Blue Pill, relay module, L298N, A4988, LM2596, TP4056, HC‑05, nRF24L01+, RC522, SIM800L, 0.96" OLED, MPU6050, HC‑SR04, DHT11, HC‑SR501 PIR, soil moisture sensor
- Tap any point for: what it is, what it does, its role on that board, and how to identify and test it
- Uses, key specs and a beginner tip for each board
- Search box for boards and parts
- Parts library (66 components) and PCB basics
- Language switch: English, Tamil, or both, plus read-aloud

## Hosting
It is a single static file, `index.html`, with no build step and no server code. Serve it from any static host (Nginx, Render Static Site, GitHub Pages).
